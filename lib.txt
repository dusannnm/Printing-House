================================================================================
LIBRARIES USED IN THE PROJECT - "Printing House" (PIA 2025/2026)
================================================================================
All npm packages install automatically with "npm install" inside the matching
folder (backend/ and frontend/), because they are listed in package.json.
The links below point to the official download / package page of each library.


--------------------------------------------------------------------------------
0. PLATFORM / TOOLS (installed manually, once)
--------------------------------------------------------------------------------
Node.js                  v22.21.0    https://nodejs.org/en/download
  JavaScript runtime the backend runs on; also provides npm.

npm                      (bundled with Node.js)
  Package manager used to install every library below.

MongoDB Community Server  v7+        https://www.mongodb.com/try/download/community
  Database. Connection used by the app: mongodb://127.0.0.1:27017/printingHouse2026

MongoDB Compass (optional)           https://www.mongodb.com/try/download/compass
  GUI for inspecting the collections.

Angular CLI (global, optional)       https://www.npmjs.com/package/@angular/cli
  Install with: npm install -g @angular/cli
  Only needed if you want the "ng" command outside of npm scripts.

5. HOW TO INSTALL AND RUN
--------------------------------------------------------------------------------
1) Install Node.js and MongoDB (see section 0) and start the MongoDB service.

2) Backend:
     cd printing_house/backend
     npm install
     npm run seed      (creates and fills the printingHouse2026 database)
     npm run build
     npm start         (API on http://localhost:4000)

3) Frontend:
     cd printing_house/frontend
     npm install
     npm start         (application on http://localhost:4200)

No library is loaded from a CDN - everything is installed through npm.
